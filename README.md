# 个人知识库开源模板

![License: MIT](https://img.shields.io/badge/License-MIT-brightgreen.svg)
![Plugins: none](https://img.shields.io/badge/Obsidian%20plugins-none-blue.svg)

> 这不是资料收藏夹，而是连接**规划、行动、证据、复盘和经验**的个人工作系统。
>
> 它由一位从业数年的产品经理把自己的私人知识库**脱敏**后整理而来。仓库里没有任何真实姓名、公司名、项目名或业务数据，所有示例都是虚构的「产品 A」。

## 先看这个：它解决什么

一个知识库真正的价值，是能稳定回答这四个问题：

| 问题 | 从哪里得到答案 |
|---|---|
| 我现在应该做什么？ | [[01-个人/00-行动与跟进/行动总览]] |
| 我以前做过什么，当时为什么这样判断？ | [[02-工作经历/00_总览/项目索引]]、[[02-工作经历/01_决策日志/决策日志]] |
| 哪些经验以后可以直接复用？ | [[02-工作经历/03_经验卡片/经验卡片索引]] |
| 我现在处在什么阶段，下一步去哪？ | [[03-复盘与规划/复盘与规划]] |

真正让它转起来的是这条闭环：

```text
规划 → 行动 → 证据 → 复盘 → 经验 → 调整规划与行动
```

## ✨ 特性

- **零插件依赖** —— 原生 Obsidian 打开即用，不需要装 Dataview、Templater 或任何社区插件
- **当前状态只有一个入口** —— 跨天行动的状态只写在行动总览，别处用链接引用，杜绝状态打架
- **五类行动编号** —— `A` 行动 / `W` 等待 / `J` 待判断 / `H` 暂缓 / `E` 历史遗留，配十字段八状态
- **完成分四层** —— `已提交 ≠ 已上线 ≠ 已验收 ≠ 已见效果`，不许合并成一句「已完成」
- **决策与经验分开记** —— 决策记「当时的约束和放弃项」，经验记「适用条件和边界」
- **原始层只读** —— 日报素材、文档原文、附件是事实之源，结论写到提炼层，出处永不断裂
- **可当 Agent Skill 装** —— 符合 [Agent Skills 开放规范](https://agentskills.io/specification)，Claude Code / Cursor / Codex / Copilot / Gemini CLI 通用
- **自带体检脚本** —— 一键查断链、字段缺失、非法状态和敏感信息

## 🚀 快速开始

### 方式一：直接当 Obsidian 库用（不用 AI）

```bash
git clone https://github.com/wangshuhui0613/personal-kb-template.git 我的知识库
cd 我的知识库
```

1. 打开 **Obsidian** → 「打开文件夹作为库」→ 选这个文件夹
2. 读 [[使用说明]]
3. 在 `01-个人/规划总览.md` 写下未来三个月最重要的**一个**方向
4. 在 `01-个人/00-行动与跟进/行动总览.md` 写下本周能推进它的**三个**行动
5. 删掉所有标着「脱敏示例」的内容

**不需要任何插件。**

### 方式二：装成 Agent Skill（让 AI 帮你建、帮你维护）

把 `skill/personal-kb/` 整个目录复制到你的 Agent 的 skills 目录：

| 平台 | 项目级 | 全局 |
|---|---|---|
| Claude Code | `.claude/skills/` | `~/.claude/skills/` |
| Cursor | `.cursor/skills/` | `~/.cursor/skills/` |
| Codex | `.codex/skills/` | `~/.codex/skills/` |
| GitHub Copilot | `.github/skills/` | `~/.copilot/skills/` |

然后直接说：**「帮我搭个知识库」**，或者日常说 **「帮我记一下这件事」**。

### 方式三：不装 Skill，只复制一段指令

打开 [[prompts/一键构建]]，把里面从「开始」到「结束」的整段复制给你的 AI 助手。

三条路的产物完全一样，区别只是你愿不愿意让 AI 碰你的文件。

## 🎬 想先看它长什么样

浏览器直接打开 `docs/demo.html`（离线可用）或 `docs/demo-cdn.html`（动效更丰富）。
左右方向键翻页，空格下一页，右下角有自动播放。

## 🔍 体检

```bash
python3 tools/vault_health_check.py --root .
```

检查项：入口文件是否齐全、双链是否断、行动表十字段是否填全、状态是否合法、是否有敏感信息。**只读不写**，退出码 1 表示有问题。

## 三条不能破的原则

1. **当前状态只有一个入口。** 一条行动的「现在怎么样了」只写在行动总览。多份状态副本必然互相矛盾。
2. **没有证据不宣称完成。** `已提交 ≠ 已上线 ≠ 已验收 ≠ 已见效果`，四个阶段分开写。
3. **原始资料和提炼结论分开。** 原始层一改，上层所有结论的出处就断了——而且没人会发现。

## 隐私边界

模板本身不含任何个人信息。但你往里写的内容是你自己的：

- 体检脚本会扫描令牌、私钥、身份证号、银行卡号等并报警；
- `07_附件/` 默认不进 Git（见 `.gitignore`），删掉这条规则等于把附件公开；
- 公开分享前，先通读 [[AGENTS]] 里的「禁止写入」。
