# screenshots

此目录放 Obsidian 实拍截图，用于 README 和文档展示。

**必须脱敏**：截图里不出现真人姓名、公司名、真实数据（手机号、金额、内部指标一律打码或换成示例值）。截图前先检查侧栏、标签页标题和通知栏。

## 建议的 4 张

| 文件 | 内容 |
|---|---|
| `01-action-dashboard.png` | 行动总览「十字段」表格全屏 |
| `02-daily-note.png` | 一篇写好的日报 |
| `03-graph-view.png` | 图谱视图（Graph view） |
| `04-insert-template.png` | 「插入模板」菜单弹出的瞬间 |

## 要求

- 每张宽 1200px 以上的 PNG；
- 截图由项目主人实拍后放入本目录，仓库里先不放图；
- 新增或更换截图时，同步检查 README 里的引用是否还对得上。
